# Paper Pilot

A browser game: fly a paper plane through an endless cave.

Play: open `index.html` in a browser.

- Record mode: from 60 sec, exits appear at random times, about every 30 sec at first and every 25 sec later. Fly up the side branch into the portal to bank your score (100 per sec, 1,000 per heart left, 500 per power-up held). A crash banks nothing.
- Campaign mode: 5 levels, 50 to 70 sec each.
- Desktop: steer with the mouse, use power-ups with A, S and D.
- Mobile (landscape): swipe to steer, tap a power-up to use it.

One self-contained HTML file: Tailwind CDN, vanilla JS, embedded font.
